# Mercedes-Benz — каталог моделей

Неофициальный информационный сайт о Mercedes-Benz: 36 моделей (актуальные и классика) с характеристиками, сравнение, избранное, история марки и технологии.

## Запуск

Откройте `index.html` в браузере — сборка и сервер не нужны.

## Структура

```
index.html       разметка страницы
css/style.css    стили (адаптив для ПК и телефона)
js/models.js     данные: модели, характеристики, история, технологии
js/app.js        логика: фильтры, поиск, сортировка, карточка модели, сравнение, избранное
img/             фотографии (Wikimedia Commons, свободные лицензии)
```

## Как добавить модель

Добавьте объект в массив `window.MODELS` в `js/models.js`. Если фото нет, укажите `img: null` — будет показана нарисованная иллюстрация нужного типа кузова (`sedan`, `suv`, `coupe`, `roadster`, `ev`, `hyper`, `van`). Чтобы добавить фото, положите `img/<id>.jpg` (ширина ~960px) и укажите `img: "<id>"`.

## Возможности

- Фильтры: новые / классика, тип кузова, AMG, избранное; поиск и сортировка
- Карточка модели с полными характеристиками, переключение ← → и закрытие по Esc, свайпу или кнопке «Назад»
- Прямые ссылки на модели: `index.html#model/sls`
- Сравнение до 3 моделей с подсветкой лучших значений
- Избранное и сравнение сохраняются в браузере
- Без внешних библиотек и шрифтов; фото с отложенной загрузкой
